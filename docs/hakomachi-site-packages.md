# HakoMachi Site Packages

Site Planner local saves download as `hakomachi-site.hako-site`.

The `.hako-site` extension is a HakoMachi-specific project package name. The underlying bytes remain a standard ZIP container so the package can include the main `hakomachi-site.hako-site.json` project file plus referenced assets such as background images, attached `.hako` building files, and STL/source assets.

## Compatibility

- New Site Planner saves use `.hako-site`.
- Imports accept `.hako-site` package files.
- Legacy `.zip` package imports continue to work for older saved projects.
- Standalone `.hako-site.json` project files still import as JSON for GitHub-backed or legacy embedded-image workflows.

Road asset and utility fabrication downloads may continue to use `.zip` when they are fabrication bundles rather than reopenable Site Planner project packages.

## File Icons

Browsers can choose the downloaded filename and extension, but they cannot reliably force a custom Finder, Explorer, or iOS file icon. Custom icons require operating-system file associations, a native app, an installer, or platform-specific PWA/file-handler support.
